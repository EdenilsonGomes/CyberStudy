# Rumevo Android pilot

This folder contains the isolated Capacitor shell used to generate the Android pilot APK without changing the web application's runtime.

- App name: Rumevo
- Android package: `com.rumevo.app`
- Current content source: the EasyPanel production URL configured in `capacitor.config.json`
- Distribution: internal APK (debug-signed) for pilot testing
- Push notifications: intentionally deferred until the Firebase configuration is provided

The APK is generated by the `Build Rumevo APK` GitHub Actions workflow.
